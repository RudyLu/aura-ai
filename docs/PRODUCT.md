# Aura

Aura is a personal wellbeing recording prototype. People record feelings, food/drinks and optional Apple Health data, view descriptive charts, talk with Aura and review small plans.

The approved v2 scope is frontend integration on `ellie/aura-v2`, using the supplied ZIP as UI authority and the three behavioral documents plus HRV PDF as product specifications. Preserve backend integrations, authentication, real records and plan history. Personal and demo data stay separate. Demo data is clearly labeled. No prototype conversation is a real Agent response.

Ellie's work includes five-topic recording, Today/Explore/Aura experiences, dynamic conversation presentation, Day 10 review/confirmation UI, HRV visualization and frontend contracts. Rudy owns Agent prompts, context, reasoning, safety policy and generation. Existing Agent implementation remains unchanged. AI-dependent states must stay visible with honest errors or unavailable status.

Real HRV relative-index baseline/bin/travel policy, new topic factors, trends and lifestyle actions need approved decisions. Native-device and live-AI integration verification remain external dependencies. Do not commit, push, create a PR, or modify main without the user's approval.
